3Mix — Avisos de componentes de terceiros
==========================================

Este arquivo lista os componentes de código aberto e de terceiros incluídos nesta
distribuição do 3Mix, suas licenças e, quando aplicável, onde obter o código-fonte
correspondente. Esta lista foi gerada a partir de FreeMix/componentes.json, o registro
interno que o próprio projeto mantém com versão, licença e papel de cada componente — não
foi inventada nem estimada.

O 3Mix é construído sobre um motor interno que é um fork do OBS Studio (libobs). O OBS
Studio é GPL-2.0-or-later. Como consequência direta dessa licença, o 3Mix como um todo é
distribuído sob os termos da GPL-2.0-or-later, e o código-fonte completo (incluindo as
modificações do fork) está disponível para qualquer destinatário desta distribuição —
ver "Oferta de código-fonte" ao final deste arquivo.

----------------------------------------------------------------------
1. Motor base
----------------------------------------------------------------------

OBS Studio (motor)
  Repositório de origem: https://github.com/obsproject/obs-studio
  Versão base: 32.2.2
  Licença: GPL-2.0-or-later
  Papel nesta distribuição: motor de vídeo, áudio, gravação e transmissão. Os binários
  desta cópia são compilados a partir do fork interno do projeto (branch
  freemix/broadcast-suite), com a base oficial 32.2.2.

----------------------------------------------------------------------
2. Plugins e componentes GPL-2.0 (texto completo da licença em 3mix-runtime/licenses/)
----------------------------------------------------------------------

Downstream Keyer
  Origem: https://github.com/exeldro/obs-downstream-keyer — versão 0.4.4
  Papel: overlays (DSK) 1 a 8 e a cena de barramentos mantida no ar.
  Modificado: sim — duas mudanças registradas em FreeMix/componentes.json (hideAfter
  inicia em zero; comando dsk_set_hide_after). Fonte completa do fork preservada em
  3mix-runtime/licenses/ (ou equivalente) junto ao provenance.json de origem.

Source Record
  Origem: https://github.com/exeldro/obs-source-record — versão 0.4.8
  Papel: MultiGravação — cada entrada grava em seu próprio arquivo.

Replay Source
  Origem: https://github.com/exeldro/obs-replay-source — versão 1.8.1
  Papel: replay instantâneo.

Move (transição)
  Origem: https://github.com/exeldro/obs-move-transition — versão 3.2.1
  Papel: transição "Merge".

Media Playlist Source
  Origem: https://github.com/CodeYan01/media-playlist-source — versão 0.1.3
  Papel: Playlist / DDR.

Source Dock
  Origem: https://github.com/exeldro/obs-source-dock — versão 0.5.1
  Papel: incluído na distribuição; sem uso ativo na mesa hoje.

Audio Monitor
  Origem: https://github.com/exeldro/obs-audio-monitor — versão 0.10.1
  Papel: incluído na distribuição; previsto para saída de barramento por dispositivo de
  áudio, sem uso ativo na mesa hoje.

Mix Track to Source
  Origem: https://github.com/semnil/MixTrack2Source — versão 1.0.2
  Papel: barramentos de áudio Master, A e B.

Advanced Masks
  Versão: 1.5.4 — Licença: GPL-2.0.

Advanced Scene Switcher
  Versão: 1.36.1 — Licença: GPL-2.0.

Cloud Closed Captions (obs-google-caption-plugin)
  Versão: 0.33 — Licença: GPL-2.0.

DistroAV (NDI)

Oferta de código-fonte (exigência da GPL-2.0-or-later)
----------------------------------------------------------------------

Como o motor do 3Mix é derivado do OBS Studio (GPL-2.0-or-later) e inclui plugins também
sob GPL-2.0, qualquer pessoa que receba esta distribuição binária tem o direito de receber
o código-fonte correspondente, nos termos da licença.

O código-fonte do fork interno (branch freemix/broadcast-suite sobre a base 32.2.2 do OBS
Studio) e os fontes originais pinados de cada plugin modificado estão preservados junto ao
projeto (ver 3mix-runtime/licenses/<componente>/ para o ZIP/tarball de origem e o arquivo
de proveniência de cada um). [CANAL DE DISTRIBUIÇÃO DO CÓDIGO-FONTE PARA TERCEIROS A
DEFINIR PELO RESPONSÁVEL DO PROJETO antes de publicar esta beta fora do ambiente de
desenvolvimento — preencher aqui o link ou meio de entrega antes de distribuir.]
